Add the `lsst.pipe.base._runtime_analyzer` subpackage for analyzing the runtimes of pipeline quanta.
That subpackage is unstable, so its interface may change without the usual deprecation notice.

The subpackage provides the `runtime-analyzer` command for summarizing per-task runtimes, ranking the slowest quanta, and exporting the results as CSV or Parquet.
Its third-party dependencies are optional: install the `[runtime]` extra for `click`, `matplotlib`, and `pyarrow`, and the additional `[kde]` extra for `scipy`, which is needed for kernel density estimates and exact statistical distributions.
